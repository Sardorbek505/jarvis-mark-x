# 🤖 ДЖАРВИС — Русскоязычный голосовой ИИ-ассистент

Клон Mark-XXXIX с полной поддержкой русского языка.  
Движок: **Google Gemini Live API** (нативный аудио, без задержек).

---

## 🚀 Быстрый старт

```bash
git clone <repo>
cd jarvis-ru
pip install -r requirements.txt
python main.py
```

При первом запуске появится экран инициализации — введите ваш **Gemini API ключ**.  
Получить бесплатно: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)

**Важно:** Если появляется ошибка "API key expired", получите новый ключ по ссылке выше и обновите файл `config/api_keys.json`

## 🔑 Требования

- Python 3.11 или 3.12

- Windows / macOS / Linux

## ⚙️ Настройка голоса

По умолчанию используется голос **Charon** (глубокий мужской).  
Другие варианты в `main.py` → параметр `voice_name`:
- `Puck` — живой, энергичный
- `Aoede` — нейтральный женский
- `Fenrir` — уверенный мужской
- `Kore` — тихий женский

## 🐛 Частые проблемы

**ModuleNotFoundError** → `pip install <название_модуля>`  
**Нет звука** → проверьте микрофон в системных настройках  
**API key expired / Invalid API key** → получите новый ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey) и обновите `config/api_keys.json`  
**Ошибка API** → проверьте ключ на [aistudio.google.com](https://aistudio.google.com)
