# 🤖 ДЖАРВИС — Русскоязычный голосовой ИИ-ассистент

Клон Mark-XXXIX с полной поддержкой русского языка.  
Движок: **Google Gemini Live API** (нативный аудио, без задержек).

---

## 🚀 Быстрый старт

```bash
git clone <repo>
cd jarvis-ru
pip install -r requirements.txt
python main.py
```

При первом запуске появится экран инициализации — введите ваш **Gemini API ключ**.  
Получить бесплатно: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)

**Важно:** Если появляется ошибка "API key expired", получите новый ключ по ссылке выше и обновите файл `config/api_keys.json`

### 🎯 Lifestyle-режимы

```
"Джарвис, режим учебы"      → Teams, ChatGPT, университет, учебная папка
"Режим работы"              → Джарвис спросит: дизайн/код/клиент?
"Режим работы, дизайн"      → Figma (или figma.com)
"Режим работы, код"         → VS Code (или GitHub)
"Режим работы, клиент"      → Telegram + почта
"Режим кино"                → Джарвис спросит название фильма
"Режим музыки"              → Джарвис спросит настроение
"Режим музыки, фон"         → Spotify + плейлист для концентрации
"Обычный режим"             → Возврат, ничего не закрывает
```

**Настройка:** все URL и приложения настраиваются в `config/modes.json` — можно подставить свой URL университета, путь к учебной папке, любимый код-редактор и т.д.

**Безопасность:** режимы только **открывают** приложения и сайты. Никогда не закрывают окна и не меняют системные настройки без явной команды.

### 🎬 Кино-плеер (продвинутое управление)

```
"Включи фильм Интерстеллар" → VK Video поиск → готов к воспроизведению
"Поставь Бэтмен"            → То же
"Пауза"                     → Space (универсально для VK/YouTube/Netflix)
"Продолжай"                 → Space (toggle)
"Полный экран"              → F (стандарт всех плееров)
"Перемотай вперёд"          → Стрелка → (10 секунд)
"Назад"                     → Стрелка ← (10 секунд)
"Громче" / "Тише"           → Системная громкость ±10%
"Выйди из фильма"           → Esc → закрытие вкладки
```

**Принцип работы:** клавиатурные команды через `pyautogui` (или PowerShell SendKeys на Windows как fallback). Работает в любом браузерном плеере — VK Video, YouTube, Netflix, Twitch.

Если `pyautogui` не установлен и не Windows — Джарвис скажет "Не могу управлять плеером, сэр" вместо краха.

### 🎵 Spotify Music-плеер

```
"Включи музыку"             → Открывает Spotify, запускает воспроизведение
"Включи Imagine Dragons"    → Поиск + автозапуск
"Поставь Любэ"              → То же
"Включи jazz"               → Поиск по жанру
"Пауза"                     → Media play/pause key (глобально)
"Продолжай"                 → Media play/pause key
"Следующий трек"            → Media next
"Предыдущий"                → Media previous
"Стоп музыку"               → Stop / pause
"Громче" / "Тише"           → Системная громкость ±10%
"Режим музыки, фон"         → Spotify + плейлист lofi/concentration
```

**Принцип работы:**
1. **Открытие через `spotify:` URI** — Windows автоматически запускает десктопный Spotify (например `spotify:search:Imagine%20Dragons` или `spotify:playlist:ID`)
2. **Web fallback** — если десктопный Spotify не установлен, открывает `open.spotify.com`
3. **Media keys через Win32 API** (`VK_MEDIA_PLAY_PAUSE`) — работают глобально, без необходимости фокусировать окно
4. **Auto-focus окна Spotify** через `pygetwindow` для надёжности

Все команды (пауза/трек/громкость) работают **глобально** — окно Spotify не должно быть в фокусе.

## ⚙️ Настройка голоса

По умолчанию используется голос **Charon** (глубокий мужской).  
Другие варианты в `main.py` → параметр `voice_name`:
- `Puck` — живой, энергичный
- `Aoede` — нейтральный женский
- `Fenrir` — уверенный мужской
- `Kore` — тихий женский

## 🐛 Частые проблемы

**ModuleNotFoundError** → `pip install <название_модуля>`  
**Нет звука** → проверьте микрофон в системных настройках  
**API key expired / Invalid API key** → получите новый ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey) и обновите `config/api_keys.json`  
**Ошибка API** → проверьте ключ на [aistudio.google.com](https://aistudio.google.com)
