# 🤖 ДЖАРВИС — Русскоязычный голосовой ИИ-ассистент

Клон Mark-XXXIX с полной поддержкой русского языка.  
Движок: **Google Gemini Live API** (нативный аудио, без задержек).

---

## 🚀 Быстрый старт

```bash
git clone <repo>
cd jarvis-ru
pip install -r requirements.txt
python main.py
```

При первом запуске появится экран инициализации — введите ваш **Gemini API ключ**.  
Получить бесплатно: [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
**Ключ сохраняется автоматически** — вводить нужно только один раз. При последующих запусках ДЖАРВИС сразу начнёт работу.

**Важно:** Если появляется ошибка "API key expired", получите новый ключ по ссылке выше и обновите файл `config/api_keys.json`

## 🧠 Новый мозг ДЖАРВИС

ДЖАРВИС теперь — не просто "голосовой пульт", а настоящий ИИ-ассистент с эмпатией и инициативностью!

### Эмоциональный интеллект

ДЖАРВИС анализирует ваши эмоции в каждом сообщении:

**Если вам грустно:**
- Вы: "Мне грустно"
- ДЖАРВИС: "Сэр, я вижу вам грустно. Может, включить КВН для поднятия настроения?"

**Если вам скучно:**
- Вы: "Мне скучно"
- ДЖАРВИС: "Сэр, вам скучно? Может, посмотреть фильм?"

**Если стресс:**
- Вы: "У меня стресс"
- ДЖАРВИС: "Сэр, я вижу вы в стрессе. Может, сделать перерыв и включить спокойную музыку?"

### Инициативность

ДЖАРВИС проявляет инициативу в подходящие моменты:

- **При эмоциях** — если грустите/скучаете, предложит помощь
- **При контексте** — если вечер и ничего не происходит, предложит фильм/музыку
- **При долгом бездействии** — спросит "Чем помочь?"

**Ограничения:**
- Не отвлекает в режимах работы/учебы
- Не навязывается — даёт право отказаться
- Не более 1 инициативы за 10 минут

### Обучение из контекста

ДЖАРВИС учится из каждого взаимодействия:

- Вы: "Люблю КВН" → ДЖАРВИС запоминает как любимую комедию
- Вы: "Люблю джаз" → ДЖАРВИС запоминает как любимую музыку
- Вы: "Меня зовут Александр" → ДЖАРВИС запоминает имя и использует его
- Вы часто включаете что-то → ДЖАРВИС добавляет в "любимое"

### Профиль пользователя

  "context": {
    "current_activity": "watching_movie",

    "recent_movies": ["Интерстеллар", "Начало"],

### 🧠 Умные напоминания (AI-powered)

JARVIS адаптирует напоминания на основе вашего поведения и эмоционального состояния:

**Адаптивные напоминания:**
- Если вы часто игнорируете напоминания за 15 минут → JARVIS начнёт напоминать за 30 минут
- Учитывает ваши паттерны (утро/вечер, выходные)
- Автоматически подстраивает время напоминаний под ваш стиль

**Эмоциональный интеллект:**
- Если вы **напряжены/устал** → мягкий тон, предложение отложить некритичные напоминания
- Если вы **в стрессе** → только критические напоминания
- Если вы **счастливы** → энергичный тон
- Если вы **сфокусированы** → краткие и прямые напоминания

**Интеграции:**
- **Spotify**: Перед важной встречей предложит приглушить музыку
- **Кино**: Если смотрите фильм → предложит приостановить за 10 минут до встречи
- **Окна**: Перед встречей не будет разворачивать новые окна

**Примеры:**
```
"Джарвис, я вижу вы напряжены. Хотите отложить некоторые напоминания?"
"Отлично! У вас встреча через 15 минут, не забудьте отчёт о продажах"
"Сэр, вы работаете уже 3 часа. Нужен перерыв? У вас встреча через 30 минут"
"Сэр, у вас скоро встреча. Приглушить музыку?"
```

**Контекстная адаптация:**
- Режим **Кино**: не прерывает во время фильма (кроме критических событий)
- Режим **Учеба/Работа**: напоминает о перерывах и дедлайнах
- Режим **Музыка**: мягко адаптирует громкость перед встречами

### 🏥 Health-напоминания (AI-powered)

JARVIS следит за вашим здоровьем и даёт своевременные напоминания:

**Отслеживание активности:**
- Автоматически отслеживает когда вы начинаете смотреть фильм или работать
- Записывает время начала и окончания активности
- Хранит историю сессий и health-алертов в `config/activity_tracking.json`

**Health-правила:**
- **Фильм > 2 часов**: "Сэр, вы уже X часов Y минут смотрите фильм. Это вредно для глаз и осанки. Хотите сделать перерыв?"
- **Работа > 1 час без перерыва**: "Сэр, вы работаете уже X минут. Хотите сделать короткий перерыв? Рекомендую встать и потянуться."
- Сообщения варьируются по длительности (чем дольше, тем настойчивее)

**Контекстная интеграция:**
- Проверяет health needs при каждом proactive запросе
- Если вы в режиме "movie" → отслеживает время просмотра фильма
- Если вы в режиме "work" → отслеживает время работы без перерыва
- Учитывает эмоциональное состояние (если вы устали — предложит отдых более настойчиво)

**Примеры:**
```
"Сэр, вы уже 2 часа 15 минут смотрите фильм. Это вредно для глаз и осанки. Хотите сделать перерыв?"
"Сэр, вы работаете уже 65 минут. Хотите сделать короткий перерыв? Рекомендую встать и потянуться."
"Сэр, вы уже 3 часа 30 минут работаете без перерыва. Это вредно для здоровья. Настоятельно рекомендую отдохнуть."
```

**Ограничения:**
- Не напоминает чаще чем каждые 30 минут для одной активности
- Не навязывается — даёт право отказаться
- Учитывает контекст (если вы в важной встрече — не прерывает)

### 🎬 Кино-плеер (продвинутое управление)

```
"Включи фильм Интерстеллар" → kinogo.mu поиск → авто-клик → полноэкранный режим
"Поставь Бэтмен"            → То же
"Пауза"                     → Space (универсально для VK/YouTube/Netflix)
"Продолжай"                 → Space (toggle)
"Полный экран"              → F (стандарт всех плееров)
"Перемотай вперёд"          → Стрелка → (10 секунд)
"Назад"                     → Стрелка ← (10 секунд)
"Громче" / "Тише"           → Системная громкость ±10%
"Выйди из фильма"           → Esc → закрытие вкладки
```

**Принцип работы:** клавиатурные команды через `pyautogui` (или PowerShell SendKeys на Windows как fallback). Работает в любом браузерном плеере — kinogo.mu, YouTube, Netflix, Twitch.

Если `pyautogui` не установлен и не Windows — Джарвис скажет "Не могу управлять плеером, сэр" вместо краха.

### 🎵 Spotify Music-плеер (Official Web API)

```
"Включи музыку"             → Открывает Spotify, запускает воспроизведение
"Включи Imagine Dragons"    → Точный поиск + автозапуск запрошенного трека
"Поставь Miyagi люби меня"  → Точный поиск с fuzzy matching
"Включи jazz"               → Поиск по жанру
"Пауза" / "Продолжи"       → Управление воспроизведением
"Следующий" / "Предыдущий"   → Переключение треков
"Громче" / "Тише"           → Громкость Spotify ±10%
"Громкость 50"               → Установка конкретной громкости
"Перемешай"                 → Включение/выключение перемешивания
"Повтор"                     → Режим повтора (трек/контекст/выкл)
"Что играет" / "Кто поет"    → Информация о текущем треке
"Включи спокойное"           → Mood mode: спокойная музыка
"Включи мотивационное"      → Mood mode: мотивационная музыка
"Включи ночной вайб"        → Mood mode: ночная атмосфера
```

**Принцип работы (NEW - Official Web API):**
1. **Spotify Web API** — официальный контроль через OAuth 2.0
2. **Точный поиск с fuzzy matching** — гарантирует воспроизведение запрошенного трека
3. **Device awareness** — автоматически выбирает активное устройство
4. **Автоматический запуск desktop app** — если нет устройств, открывает Spotify
5. **Mood mode** — генерация плейлистов через Spotify Recommendations API
6. **Track cache** — кэширование популярных запросов для быстродействия
7. **Refresh token** — не требует логина каждый запуск

**Преимущества перед старой версией:**
- ✅ Гарантирует воспроизведение **запрошенного трека**, не последнего проигранного

### 🔑 Обязательная настройка Spotify Web API

**Важно:** Новая версия требует Spotify API credentials для работы.

Шаги:
1. Зайдите на https://developer.spotify.com/dashboard
2. Создайте приложение (Create App)
3. Получите Client ID и Client Secret
4. Добавьте Redirect URI: `http://127.0.0.1:8888/callback`
5. Получите authorization code и refresh token (см. ниже)
6. Добавьте в `config/api_keys.json`:
```json
{
  "spotify_client_id": "your_client_id",
  "spotify_client_secret": "your_secret",
  "spotify_redirect_uri": "http://127.0.0.1:8888/callback",
  "spotify_refresh_token": "your_refresh_token"
}
```

**Получение Refresh Token:**
1. Откройте auth URL: `https://accounts.spotify.com/authorize?client_id=YOUR_CLIENT_ID&response_type=code&redirect_uri=http://127.0.0.1:8888/callback&scope=user-read-playback-state+user-modify-playback-state+user-read-currently-playing`
2. Авторизуйтесь в Spotify
3. Вы будете перенаправлены на `http://127.0.0.1:8888/callback?code=AUTH_CODE`
4. Скопируйте AUTH_CODE из URL
5. Обменяйте код на refresh token через API (или используйте готовый refresh token если есть)

**Без API** — Джарвис честно сообщит: "Spotify недоступен, сэр. Пожалуйста, настройте credentials."

## 🎬 Кино (kinogo.mu + Selenium)

**Команды:**
- «Включи фильм Интерстеллар» — автоматически выбирает первый результат на kinogo.mu, включает во весь экран
- «Пауза», «Продолжи» — управление воспроизведением
- «На полный экран» — полноэкранный режим

**Источники:**
- kinogo.mu — автоматический выбор первого результата через Selenium
- Полноэкранный режим и голосовое управление после автоплея

**Технологии:**
- Selenium WebDriver для автоматического браузерного взаимодействия
- ChromeDriver (автоматическая установка через webdriver-manager)
- Headless Chrome для фонового выбора видео

**Установка Selenium:**
```bash
pip install selenium webdriver-manager
```

**Совет для лучшей точности:**
Для более точного нажатия кнопки play, вы можете добавить скриншот кнопки:
1. Откройте любой фильм на kinogo.mu
2. Сделайте скриншот кнопки play (обычно треугольник в центре плеера)
3. Сохраните как `assets/play_button.png` в папке проекта
4. ДЖАРВИС будет автоматически находить эту кнопку на экране

**Как это работает:**
1. ДЖАРВИС открывает kinogo.mu поиск в фоновом Chrome (без интерфейса)
2. Selenium находит первый видео-результат
3. Кликает на него автоматически
4. Проверяет что видео открылось (URL изменился на video-XXXXX_XXXXX)
5. Включает полноэкранный режим
6. Вы говорите команды для управления (пауза, перемотка, громкость)

**Пример использования:**
- Вы: "Джарвис, поставь фильм Тор 2"
- Уходите на кухню
- Когда вернётесь: фильм уже идёт во весь экран
- Вы: "Пауза", "Громче", "Перемотай вперёд"
