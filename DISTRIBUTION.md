# Руководство по распространению и установке JARVIS Mark X

JARVIS Mark X теперь полностью готов к работе в качестве автономного настольного приложения для Windows без необходимости настраивать Python, консоль и окружение.

---

## 🚀 Для конечного пользователя (3 шага до старта)

1. **Запуск**: Скачайте и запустите `JARVIS.exe` (или установите через `JARVIS_Setup_v1.0.exe`).
2. **Первичная настройка (Setup Wizard)**:
   - В открывшемся окне нажмите **«🔗 Получить бесплатный ключ»** (откроется страница Google AI Studio).
   - Скопируйте ключ `AIzaSy...` и нажмите **«Проверить ключ»** (загорится `✅ Ключ активен`).
   - Проверьте микрофон и выберите голос.
   - Нажмите **«Сохранить и запустить JARVIS»**.
3. **Использование**:
   - Ассистент появится на экране и свернется в системный трей (у часов справа внизу).
   - Говорите голосом или открывайте меню по правому клику на иконку реактора.

---

## 🛠️ Для разработчика: Сборка дистрибутива

### 1. Компиляция в `.exe` (PyInstaller)
Для сборки автономного пакета со всеми зависимостями запустите:
```powershell
python scripts/build_exe.py
```
*Результат*: готовая папка `dist/JARVIS/` с файлом `JARVIS.exe`.

### 2. Создание установщика Windows (Inno Setup)
1. Установите [Inno Setup 6](https://jrsoftware.org/isdl.php) (бесплатно).
2. Откройте файл `scripts/installer.iss` в Inno Setup Compiler и нажмите **Compile (Ctrl+F9)** (или выполните команду `iscc scripts/installer.iss`).
*Результат*: единый установочный файл `dist/JARVIS_Setup_v1.0.exe`.

---

## ⚙️ Архитектура и особенности

- **BYOK (Bring Your Own Key)**: Пользователи используют собственные бесплатные квоты Google Gemini API (1500 запросов/день бесплатно).
- **System Tray**: Программа не захламляет панель задач и работает в фоновом режиме в системном трее Windows (`QSystemTrayIcon`).
- **Синтез речи**: Встроенный бесплатный нейросетевой голос Edge-TTS (`ru-RU-DmitryNeural` / `ru-RU-SvetlanaNeural`) с поддержкой Fish Audio.
- **Автозапуск**: Поддержка автозапуска вместе с Windows через реестр (`HKCU\Software\Microsoft\Windows\CurrentVersion\Run`).
