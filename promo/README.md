# JARVIS — промо-ролик

Рекламный моушн-ролик (9:16, 1080×1920, 30 fps, ~24 сек) в стиле референса
Moolah: жёсткие смены фона blue / pink / red / yellow / green, 3D-телефоны,
выпрыгивающие карточки, плоские геометричные иллюстрации, крупные заголовки
с подсветкой нового слова розовым.

Готовый файл: **`jarvis_promo.mp4`**.

## Пересобрать
```bash
pip install imageio-ffmpeg            # ffmpeg (или свой в PATH / $FFMPEG)
npm i -g playwright                   # + браузер Chromium
python3 promo/make_soundtrack.py      # синтезирует promo/soundtrack.wav
NODE_PATH=$(npm root -g) node promo/render.cjs          # → promo/jarvis_promo.mp4
NODE_PATH=$(npm root -g) node promo/render.cjs --stills 3,8.5   # отдельные кадры
```
Открыть `promo/index.html` в браузере — ролик проигрывается вживую (без звука).

Тексты, экраны и тайминги — в `index.html` (`S` — экраны, `scene(...)` — сцены).
Шрифт Onest (OFL) лежит в `fonts/`. Музыка сгенерирована кодом — без
чужих семплов и лицензий.
