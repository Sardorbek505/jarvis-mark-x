# Утренний брифинг — Design Spec

**Дата:** 2026-05-11  
**Статус:** Approved  
**Фича:** Morning Briefing — автоматический утренний брифинг при старте и по команде

---

## Проблема

ДЖАРВИС не даёт проактивного обзора дня при запуске. Пользователь должен вручную спросить про погоду, потом про календарь, потом про новости — три отдельных запроса. Настоящий ДЖАРВИС из Iron Man начинает день сам.

---

## Решение

Один `morning_briefing` tool, который при вызове собирает погоду + календарь + топ-новости и возвращает связный монолог в стиле ДЖАРВИС. Запускается автоматически при старте (6–10 утра) и по голосовой команде в любое время.

---

## Архитектура

### Новый файл: `actions/morning_briefing.py`

Единственная публичная функция:

```python
def morning_briefing(parameters: dict, player=None) -> str
```

Внутренний порядок вызовов:
1. `load_memory()` → имя пользователя, город
2. `weather_action({"city": city})` → строка с погодой
3. `get_events("today")` → события календаря на сегодня
4. `NewsManager().fetch_all_news()` → список `NewsArticle`, берём топ-3 по relevance
5. Сборка финального текста в стиле ДЖАРВИС

Каждый шаг обёрнут в `try/except` — fallback на пропуск блока.

### Изменения в `main.py`

**1. Новый tool в список `TOOLS`:**

```python
{
    "name": "morning_briefing",
    "description": (
        "Утренний брифинг — погода, события на сегодня, главные новости. "
        "Вызывай когда пользователь говорит 'брифинг', 'что сегодня', "
        "'доброе утро', 'введи в курс дня'. "
        "Также вызывай автоматически при старте сессии если сейчас утро (6-10)."
    ),
    "parameters": {"type": "OBJECT", "properties": {}, "required": []}
}
```

**2. Tool handler в `_handle_tool_call()`:**

```python
elif name == "morning_briefing":
    result = morning_briefing(args, player=self.player)
```

**3. Авто-триггер в `_initialize_session()` или аналоге:**

```python
hour = datetime.now().hour
if 6 <= hour < 11:
    await session.send(
        "Сейчас утро. Немедленно вызови инструмент morning_briefing "
        "без каких-либо вступительных слов.",
        end_of_turn=True
    )
```

---

## Стиль речи

Монолог строится по структуре ДЖАРВИС из Iron Man:

- Всегда начинается с **"Доброе утро, сэр."** (или с именем если известно)
- Погода — конкретные цифры + короткий вывод-рекомендация
- Календарь — перечисление событий с временем, приоритет ближайшему
- Новости — 2–3 заголовка, кратко, допустима лёгкая ирония
- Завершение — **"К работе готов, сэр."** или аналог с вопросом

Тональность: формальная, уверенная, без лишних слов, редкий сухой юмор.

---

## Graceful Fallback

| Компонент | Если недоступен |
|-----------|-----------------|
| Погода | «Данные о погоде временно недоступны, сэр.» |
| Календарь | Блок пропускается, либо «Расписание чисто.» |
| Новости | «Новостная лента недоступна.» |
| Имя/город | Использует «сэр» и город по умолчанию из config |

