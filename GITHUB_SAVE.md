# Автоматическое сохранение на GitHub

## Как использовать

### Windows:
```bash
cd D:\jarvis-ru\jarvis-ru
save_to_github.bat
```

### Linux/Mac:
```bash
cd D:\jarvis-ru/jarvis-ru
./save_to_github.sh
```

## Что делает скрипт

1. Добавляет все изменения в git
2. Создаёт коммит с автоматической меткой времени
3. Пушит на GitHub (origin/master)

## Когда запускать

- После окончания работы над проектом
- После важных исправлений
- Перед закрытием сессии

## Примечания

- Если нет изменений - скрипт сообщит об этом и завершится
- Если возникнет ошибка - скрипт покажет сообщение и остановится
- Коммиты будут с меткой времени: "Auto-save 2026-05-11 16:58:00"
