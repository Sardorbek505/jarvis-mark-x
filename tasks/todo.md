## Ревью
Бот-двойник собран из 4 слоёв на едином durable-хранилище (Postgres через
DATABASE_URL, fallback SQLite):
1. Долгая память + досье + авто-обучение фактам
2. Режимы личности (ментор/друг/бизнес) поверх базовой личности
3. Задачи/календарь с NL-парсингом дат, видимые ассистенту в контексте
4. Проактивный секретарь: сам пишет утром и вечером

Принципы соблюдены: минимальное воздействие (один стор, переиспользование
context_provider и _system_for), без костылей, миграции безопасны, всё
покрыто прогонами. Для вечной памяти на Render — один шаг: DATABASE_URL (Neon).
